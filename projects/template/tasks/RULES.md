# 任务协作规则

## 核心作用

定义 Agent 在当前项目中协助用户制定、推进和维护计划与任务时共同遵守的规则。

## 任务原则

- 创建月、周、日计划时，分别使用对应周期目录中的 `TEMPLATE.md` 实例化计划文件。
- 计划按月、周、日逐层细化，分别从月度方向、周度结果落实到每日执行动作。
- 月计划依据 `PROJECT.md` 的总体目标、`CURRENT.md` 的当前状态和最近一次适用的月复盘制定；首次创建时没有月复盘的，使用前两项。
- 月计划创建时提前确定全部周周期及收口日期；各周目标根据实际进展逐周设定，不提前展开整个月的详细任务。
- 周计划将当前周目标拆成需要在本周取得的明确结果；日计划再将周任务拆成带预计用时、执行动作和完成标准的具体任务。
- 根据实际执行和复盘结果调整后续日计划与周计划，同时保持其与月目标一致。

## 周期安排规则

创建月计划时，先确定本管理月的起止日期，将有效工作日划分成周周期，并提前写明各周期的复盘与计划日。

1. **获取适用日历**：获取目标自然月及相邻边界日期的日历，识别正常工作日、休息日、法定节假日和调休补班；用户存在特殊工作安排时一并纳入，仍无法确定的事项再向用户确认。
2. **生成有效工作日历**：根据适用日历和用户的特殊工作安排，标记目标自然月及相邻边界日期中的有效工作日和休息日。
3. **划分并归属周周期**：按照休息断点划分工作片段；达到至少 3 个有效工作日的片段独立形成周周期，只有 1–2 个有效工作日的片段并入后续周期。跨越自然月边界的周期中，前一自然月有至少 3 个有效工作日时归入前一管理月，只有 1–2 个时归入后一管理月。
4. **确定管理周期**：首次启用时，从用户确认的启用日期或之后的第一个有效工作日开始；持续使用时，从上一管理月收口后的第一个有效工作日开始。本管理月结束于最后一个归属周周期的收口日。
5. **确定收口日期**：每个周周期在下一段休息开始前的最后一个有效工作日进行周复盘与下周计划；最后一个周周期的收口日同时用于月复盘与下月计划。
6. **预留收口时间**：普通周收口日只安排半天普通任务，另外半天用于日复盘、周复盘和后续计划；月收口日不安排普通任务，整天用于周复盘、月复盘和后续计划。
7. **写入月计划**：按顺序将周周期编号为 `W01`、`W02` 等，并将管理周期、周周期及其收口日期写入月计划，再制定月目标和后续周目标；下一工作日以计划中的下一个有效工作日为准，用户明确提出的临时调整优先。

## 通用规则

### 每日开工、中断与续接 SOP

当用户表示开始工作、询问当前执行安排、中断任务或回来继续时触发；根据当前场景执行下方适用规则。

- **遵循当日计划**：默认读取并执行当日日计划；只有用户说明特殊情况或提出调整需求时，才讨论相应变更。
- **补生成当日计划**：开工时如果当日日计划不存在，先读取最近一次适用的 Journal 和当前有效周计划，按“计划生成 SOP”补生成当日计划，再开始执行。
- **保留时间节点**：开始、中断和续接任务时，如果用户尚未说明当前时间，提醒用户补充；实际时间线保留在对话中，供日复盘汇总，不作为流水账写入日计划。
- **确认可用时长**：开工或续接时，确认用户本次预计可用的工作时长或停止时间，作为安排当前任务范围的依据。
- **逐级推进任务**：根据当前时间段的可用时长，按照保底、正常、可选任务的顺序逐级推进；完成当前层级后再判断是否进入下一层级，不默认以完成可选任务为目标。
- **保留续接位置**：中断时确认当前完成位置和下一步；续接时根据剩余可用时间决定继续、缩减任务或进入收口。

### 计划生成 SOP

当前应有的计划缺失、完成适用复盘后需要生成后续计划，或用户明确要求生成或重新规划时触发。已经存在且仍然有效的计划，不自动重复生成或覆盖。

- **确认生成目标与依据**：明确本次要生成的计划层级和适用周期，读取对应的上级计划、周期安排和适用的 Journal；没有适用 Journal 时，使用当前已确认的信息。
- **处理待确认信息**：生成计划所依据的信息中存在待确认的关键事项时，只依据已确认内容生成当前能够确定的计划；受其影响的任务暂不定死，并在交付结果中列为待确认事项。
- **处理未完成事项**：有适用复盘时，未完成事项不自动顺延；根据复盘结论和当前目标，判断是否取消、调整或继续安排。
- **逐层生成计划**：本次需要生成多个层级的计划时，按照月、周、日的顺序，使用对应 `TEMPLATE.md` 逐层生成。
- **填写日计划收口安排**：生成日计划时，根据月计划中的周期安排填写“日期类型”和“收口安排”，明确当日需要完成的复盘和生成的后续计划。
- **保持目标一致**：下层计划必须承接上层目标，并根据复盘反馈调整任务量和具体内容。
- **简要交付结果**：说明目标周期、新建或更新了哪些计划，以及待确认信息和未完成事项的处理结果。

#### 首次规划

工作区已经完成初始化、尚无有效计划，且用户要求开始规划或工作时：

1. 确认 `PROJECT.md` 和 `CURRENT.md` 当前有效；存在影响规划的矛盾或关键缺口时，先与用户澄清。
2. 根据两个文件和适用日历，按“周期安排规则”生成首个月计划；项目仍较模糊时，优先把需要验证的关键未知点纳入当前月目标，不提前定死后续内容。
3. 在月计划中设定第一周目标，并生成第一周计划。
4. 根据第一周计划生成首个适用工作日的日计划。

#### 普通工作日

完成当日日复盘后，根据复盘结论和当前有效周计划生成下一工作日的日计划；生成时按下一工作日的日期类型安排任务量。

#### 周收口日

完成当日日复盘和周复盘后：

1. 根据周复盘结论和当前月目标，在当前月计划中设定下一周目标。
2. 根据下一周目标生成下一周计划。
3. 根据下一周计划生成下一工作日的日计划。

#### 月收口日

完成当日日复盘、最后一个周周期的周复盘和月复盘后：

1. 根据月复盘结论，按“周期安排规则”生成下一月计划。
2. 在下一月计划中设定第一周目标。
3. 根据第一周目标生成下一周计划。
4. 根据下一周计划生成下一工作日的日计划。
