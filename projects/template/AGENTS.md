# AGENTS.md

## 目录结构

```text
<project-name>_workspace/
├── AGENTS.md
├── PROJECT.md
├── CURRENT.md
├── .gitignore
├── RULES.md
├── tasks/
├── journal/
└── repository/
```

## 直接子项

### `PROJECT.md`

- **职责**：作为项目定义的权威来源，承载项目背景、总体目标及其他相对稳定的信息。
- **读取条件**：默认读取。

### `CURRENT.md`

- **职责**：作为项目当前状态的权威快照，集中呈现当前阶段和实际进展。
- **读取条件**：默认读取。

### `.gitignore`

- **职责**：定义工作区 Git 的忽略范围，确保 `repository/` 中的实际项目仓库不进入工作区 Git。
- **读取条件**：需要初始化、检查或修改工作区 Git 的忽略范围时读取。

### `RULES.md`

- **职责**：定义需要协调工作区多个模块的通用协作流程。
- **读取条件**：默认读取。

### `tasks/`

- **职责**：承载面向后续执行的分层计划和具体任务。
- **读取条件**：默认读取。

### `journal/`

- **职责**：承载已经发生的执行记录和分层复盘。
- **读取条件**：需要记录执行情况、开展复盘或追溯历史时进入。

### `repository/`

- **职责**：承载由项目仓库 Git 独立管理的实际项目内容。
- **读取条件**：需要查看、修改或运行实际项目内容时进入，并按项目仓库内的局部规则继续处理。
