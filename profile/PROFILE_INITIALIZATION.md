# 用户画像与协作规则初始化与复核

## 核心作用

引导当前用户首次初始化 `PROFILE.md` 和 `COLLABORATION.md`，并在必要时复核相关章节。

## 共同原则

1. 用户应按当前真实情况和意愿回答；不清楚或不愿记录的内容可以跳过。
2. 用户难以回答时，Agent 应改用具体表述、场景、示例或非穷举选项辅助思考，但不得代替用户作答或诱导结论。
3. Agent 只根据用户表达整理拟写内容；关键事项不明确时先询问用户，内容经用户确认后才能落盘。

## 首次初始化流程

1. 首次初始化可以暂缓；用户未选择开始或继续时，保留“待初始化”标记，并按工作台默认规则处理当前任务。同一 session 内不重复提醒。
2. 先初始化 `PROFILE.md`，再结合已确认画像初始化 `COLLABORATION.md`。
3. 按引导问题逐章进行，默认每次处理一个章节；用户愿意集中回答时可以合并处理。
4. 某章节确认后写入内容并移除其“待初始化”标记；用户明确跳过时，保持章节为空并移除标记。
5. 中断时保留未完成章节的标记，下次从剩余章节继续。
6. 两个文件不再存在“待初始化”标记时，首次初始化完成。

## 章节复核流程

1. 先确定存在偏差或需要重新讨论的章节，并由用户确认复核范围。
2. 读取现有内容，只使用相关章节的引导问题重新讨论。
3. 保留仍然有效的内容，只修改用户确认发生变化的部分，不添加“待初始化”标记。
4. 约定范围内的章节全部处理后，本次复核完成。

## `PROFILE.md` 引导问题

根据当前流程使用相关章节的引导问题；用户已有回答能够覆盖相关问题时，不重复询问。

### 基本背景与当前阶段

- 目前主要有哪些身份或角色，工作、学习和生活大致处于什么状态？
- 当前处于怎样的发展阶段，正在经历哪些重要变化？
- 哪些个人背景会持续影响后续目标、选择或行动？

### 长期方向与价值取向

- 长期希望走向什么方向，或者形成怎样的生活与工作状态？
- 当前最看重哪些方面，做重要选择时通常优先考虑什么？
- 有哪些不希望轻易牺牲的原则或边界？

### 能力、资源与持续约束

- 当前具备哪些能力、优势和经验，又有哪些明显不足？
- 有哪些可以长期利用的时间、工具、环境、关系或其他资源？
- 哪些现实约束会持续影响行动和选择？

### 当前自我认知

- 当前如何理解自己的性格、思维方式和行为倾向？
- 在动力、情绪或行动方面，经常出现哪些稳定模式？
- 已经意识到哪些盲点、常见困扰或希望继续改善的方面？

## `COLLABORATION.md` 引导问题

使用本组问题前，先读取 `PROFILE.md` 中已经确认的内容，并结合用户背景、方向、能力、约束和自我认知补充真正相关的问题；画像只用于辅助提问，不直接转化为协作规则，最终偏好仍由用户确认。

### 沟通与表达

- 希望回答偏简洁还是详细，是否优先给出结论、依据或示例？
- 对语言风格、专业术语、内容结构和解释深度有什么偏好？
- 当表达不清楚或出现焦虑、迷茫等情绪时，希望 Agent 如何询问和回应？

### 讨论与决策

- 信息不足时，希望 Agent 在哪些情况下主动询问，哪些低风险细节可以合理判断？
- 讨论方案时，希望如何呈现选项、利弊、依据和推荐意见？
- 当 Agent 发现风险、矛盾或不同意见时，希望以什么方式提出并协助决策？

### 任务推进与反馈

- 希望任务计划拆分到什么程度，哪些节点需要先讨论或确认？
- 任务执行期间，希望以什么频率和形式了解进展、问题与调整？
- 任务完成后，希望 Agent 如何检查结果、总结过程和开展复盘？
